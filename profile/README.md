## TrueIP: dedicated static IPs from Mumbai

[TrueIP](https://www.trueip.in/?utm_source=github&utm_medium=org) gives your outgoing requests one fixed IP address that you whitelist once. Use it when a broker, API, exchange or business app only accepts calls from a registered IP.

- **One IP per account.** Never shared with another customer, never rotated, and kept the same on renewal.
- **IPv6 or IPv4.** IPv6 is ₹50 a month and IPv4 ₹200 a month, plus GST, with a GST invoice on every payment.
- **Delivered as an authenticated HTTP proxy.** Each IP has its own host, port, username and password, and works with any language or tool that supports a proxy. Outgoing connections only.
- **Hosted in Mumbai** on our own routed address range.
